# Split-half ceiling, attempt 3

This attempt supersedes the missing-data blockers recorded in STATUS.md. The request authorizes HTTP range reads of exactly the three official 2025 H1 releases listed in runtime.URLS. No other network source is used. No raw file or raw matrix slice is saved. The 168 identities come from the frozen ../results/baseline.npz, never from outcome-based selection. No expression row is logically sliced unless its target belongs to that whitelist or is a non-targeting control. Metadata labels for the full objects are read to apply this restriction.

The local remote.py adapts model_v6/remote_h5.py: read-only HDF5 file interface, bounded RAM cache, exact URL allowlist, redirects disabled, anonymous requests with trust_env=False, ETag/If-Match, HTTP 206 and Content-Range verification, and retries. HDF5 chunks and HTTP blocks can physically contain bytes outside a selected row, but unselected rows are never materialized or included in arithmetic. The CSR reader partitions each row block into contiguous eligible runs and never bridges an ineligible row. Only indptr and obs/var metadata are read panel-wide. The raw expression block is discarded after reduction.

Controls have the same 38,176 obs IDs in all three releases. Their sorted-ID SHA256 must equal the retained original acquisition receipt. They are read numerically only from Training. Other releases skip controls before expression slicing. Each cell uses a keyed BLAKE2b hash of its obs ID, one-byte digest with the low bit as the half, and the eight-byte little-endian seed as key. Seeds are 20261027 through 20261031. Different obs IDs give independent Bernoulli half assignments; halves need not have equal sizes. All seeds are reduced in one expression pass. A dropped range request is retried; an interrupted process resumes from per-label cursors.

For each incomplete target/control, stream_halves.py keeps half-A count sums, arithmetic-CPM sums and squared-CPM sums for all five seeds, plus full sums and cell counts. Arithmetic CPM is counts divided by the cell's native whole-library total times 1e6. All live sums are float64. Checkpoints are lossless byte-shuffled zlib, one file per target/control, with a cursor and counts in its header. Each shard is atomically replaced; its own cursor makes partially completed checkpoint rounds resumable without double counting. Full sums are accumulated afresh from selected expression, then checked against the whitelisted rows of the original summaries (counts exact; moments floating tolerance). Half B is full minus A, without a second expression pass. The retained summaries are not a substitute for streamed halves.

The pseudobulk probability is native count_sum divided by its sum over ALL 18,080 native genes, before alignment to the original 18,077 measured-gene axis. The response is log1p(50000*p_target) minus log1p(50000*p_control), using the corresponding independently split NTC half. Each target's own gene is zeroed in truth and prediction, exactly as bio_gap. B0 is the fixed integer-rendered realized response in the parent's verified baseline. The full newly streamed response must recover the parent's truth within its float32 storage precision.

For every seed, select 56-target norm terciles using only A, with identity as deterministic tie-breaker, and evaluate B. Separately compute the existing moment proxy using only A: two-sample normal p-values from unbiased arithmetic-CPM variances and cell counts, own gene p=1, BH 0.05 on the original measured axis, strict '<', and bins <10, 10–999, >=1000. This is not Wilcoxon n_conf. Repeat with B selecting and A evaluating. Existing full-data proxy memberships are not reused for this selection.

Cosine is a macro average across selected targets. E is sum squared error divided by sum evaluation-half response energy, not a mean of target-normalized E. Replicate cosine is cos(b_A,b_B); replicate E is ||b_A-b_B||²/||b_evaluation||². B0 is scored against the evaluation half using the same coordinates. Average the two directional bin metrics with equal weight within a seed, then report the mean, sample SD (ddof=1), and min/max across five seeds. A bin missing either role is NA for that seed; five-seed summary metrics require all five valid seed averages. Mean n and its directional range expose variable bin sizes. Ratios divide the final B0 mean by the final replicate mean, not per-target ratios. Five partitions share cells and controls: their SD is partition sensitivity, not an independent experimental-replicate confidence interval.

Spearman–Brown is applied per target, R_full=2*r_half/(1+r_half), then averaged using the same memberships, roles and seeds. This approximates repeat-full uncentered-vector agreement under parallel-half independent-error assumptions. The ideal noiseless-signal predictor's full-data cosine is approximately sqrt(R_full); this is distinct from repeat-full agreement. Negative/invalid reliability values are not silently clipped. Unequal hash-half sizes, heteroscedastic count noise, nonlinear log pooling, uncentered cosine and selection weaken the approximation. No Spearman–Brown E correction is asserted. Both half B0/replicate fractions and full B0/ideal-signal fractions are retained.

finalize_release.py reconstructs each complete target's native half probabilities, independently replays every metric and normal/BH calculation, and verifies the streamed full sums against the original whitelist summaries before discarding that target's completed checkpoint. NumPy longdouble has only 53-bit precision on this Mac, so these are independent float64 recomputations. Three predetermined targets (baseline indices 0, 84, 167) additionally receive full-coordinate 50-decimal-digit mpmath checks for seed 20261027, both roles. Only verified scalar records are retained for completed targets. verify_halves.py then checks those receipts, memberships, directional aggregation and five-seed summaries. This is numerical verification of the diagnostic, not a biological ground-truth certificate or a new performance claim.

Run in this directory with the shared venv, one numerical worker and BLAS threads one:

```
nice -n 10 python -B stream_halves.py > stream.log 2>&1
nice -n 10 python -B analyze_halves.py > analysis.log 2>&1
nice -n 10 python -B verify_halves.py > verify.log 2>&1
```

The runtime audits write confinement and the two forbidden paths. df -g / and exact free bytes are checked before streaming and every block; abort below 30 GiB. Checkpoint writes check projected footprint against 195 MB, including atomic replacement. All writes stay here, no numerical process may outlive the session, and the stream enforces a 5.8-hour wall limit. No submission, packaging, upload, promotion, GPU, cloud, git commit, or other download occurs. Prior code/method credit and network-limited prior-art scope are in PRIOR_ART.md.
