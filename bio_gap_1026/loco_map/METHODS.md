# Frozen design before outcome evaluation

Five recipient contexts: H1_full (168 allowed training targets), K562_GWPS_full (6,864 before exclusions), RPE1 (2,016), HepG2 (1,818), Jurkat (2,137). The 79 held-out H1 target identities are removed from EVERY bank's training/evaluation rows and fallback means, using only ../results/provenance.json metadata. Counts after exclusion are recorded with results. This stricter identity exclusion was added before any outer-recipient outcome evaluation; the initial inner-only timing probe was discarded. K562 excludes every K562-family bank, including its essential/GWPS variants. All 13 manifest banks except H1_cached are eligible donors. All arms use the 6,006-gene measured intersection. Bank hashes must match the existing manifest. H1_full identities must equal ../results/baseline.npz. No H1 held-out outcomes are opened.

For outer recipient R, no perturbation row from R may enter fitting, source construction, normalizers or tuning. For inner validation context V, both R and V are removed from all training sources. A training recipient C also excludes itself from its own source features. Outer R labels are passed only to the final evaluator. Same-target observations in other contexts are legal: this is unseen-context generalization, not unseen-target generalization. Gene/target identities and control expression are legal; the fixed measured-axis intersection is descriptive metadata.

Plain transfer reproduces the family balancing and expression compatibility in model_billmB/dataset.py: for each available same-target bank row, weight exp(-mean(abs(log1p(50000*c_R)-log1p(50000*c_source)))) / number_of_matching_banks_in_that_family, then normalize the weighted sum. All vectors use the common measured axis. Recipient controls are the mean of the recipient bank's control probabilities (controls only), held constant over its targets, avoiding target-dependent batch metadata at inference. With no exact donor, use each eligible donor bank's mean response/control, with family balancing, as in Sources.features. Mark coverage. This is the plain B0-style component, not the full learned/count-emitted B0.

Pooled map: through-origin ridge/RRR on unit-length plain-transfer input vectors. An uncentered randomized SVD (256 input components, 16 oversamples, two power iterations, fixed seed) is fitted on TRAINING INPUTS only to bound CPU/memory. Report retained source energy. Training rows receive sqrt(1/n_C) weights, so recipient contexts have equal loss weight. Label amplitude remains raw logCP50k delta; own-target genes are zeroed. Ridge penalty is lambda times mean feature-Gram diagonal. Grid lambda={0.1,1,10}, output rank={20,80,unrestricted}. Output RRR is the exact minimizer in this fitted 256-dimensional input space, using the top eigenspace of the ridge-whitened cross-covariance times its transpose. No output PCA sees validation/outer labels. This pooled-input map is a bounded approximation to, not a numerical replay of, align's source-family kernel map.

Control-conditioned map: same fitting/grid, with per-recipient gene weights w_C(g)=sqrt(1+log1p(50000*c_C(g))), normalized to RMS one. Fit unit-normalized input P_C*w_C to output Y_C/w_C; multiply predictions by w_C. This gives D_C W D_C conditioning using ONLY controls, with no fitted context identity or recipient outcomes.

Hyperparameters maximize macro mean inner-context cross at each context's plain-transfer centered spread. Bounded blends jointly select the same hyperparameters and weight in {0,.005,.01,.02,.03,.05,.1,.2,.5,1}. Each map component is scaled to its recipient's plain-transfer centered spread using predictions only. The blend is again matched descriptively for scoring. Require, in EVERY training validation recipient, paired mean deltaPDS - 1.96*SE >= -.005, then maximize macro matched cross. Weight zero is available. Ties use fixed grid order. No held-out R metric changes the grid or selector.

H1-direct map: use align's modal lambda=.1 and rank40, fixed from the prior report. Refit the exact source-family concatenated unit-vector kernel on H1 training168 responses, on the common gene axis, excluding H1 AND outer R from all sources (including H1's training features). Query R with the same remaining source families. No R outcomes or R-derived parameter choice. This is a source-exclusion-adjusted transfer of the H1-fitted construction; applying the old kernel without removing R would leak R outcomes into its H1 fit.

Metrics exactly follow align: own-target coordinate zero for cross/energy; all recipient-panel target genes removed from all vectors for PDS, cosine retrieval, n-1 normalized rank and midrank ties. T=sum||Y||², C=dot/T, Q=energy/T, A=C/sqrt(Q), centered B=sum||q-mean(q)||²/T. Match the whole delta, including its mean, to plain transfer B. Retain centered cross separately. For 2,000 paired target bootstrap draws (seed 20261026), rematch B within each draw; fitted predictions and PDS candidate panel stay fixed. Report deltaC and deltaPDS intervals versus plain transfer; no multiplicity correction. Final acceptance: deltaC CI lower>0 and mean deltaPDS>=-.005 in >=3/5 recipients, including H1 beating B0. Also retain stricter PDS-CI noninferiority.

H1 additionally evaluates frozen B0 on 6,006 genes and exactly replays its original 18,077-gene cross/PDS. For the historically comparable full-axis test, apply the training-selected blend weight to B0 plus the map on the shared coordinates, preserving B0 on unmodeled coordinates; match full B0 B. This full-axis blend is a partial-gene update, explicitly distinct from the 6,006-gene plain-transfer comparison. No held-out H1 labels select weight, map or blend scale. Both B0-based component and blend spread matching use predictions only.

Independent verification is implemented separately from search, with primal normal-equation/RRR checks, scalar/native PDS replay, all final metrics and bootstrap draws, exact dyadic cross/energy/centered-spread certificates for float32 evaluation arrays, and high-precision matched-cross reconstruction. Verification certifies these local vector diagnostics only. Official MSE is not measurable locally; final D/E/F phase is blind.

All writes stay here. CPU only; one worker, one BLAS thread, nice -n 10; free space >=30.5 GiB before heavy stages (user-authorized revised threshold), abort below 30. No downloads, rendering, packaging, submissions, uploads, promotion, commits or forbidden-path access. Reproduction commands and actual verification coverage are recorded with results. After the initial run hit the former 31.5-GiB disk guard, storage was changed to float32 preallocated training arrays, with double-precision sufficient statistics and blockwise exact verification; the mathematical model/grid stayed fixed. No map-arm outer outcomes had been scored at that stop. The resumed run reuses the completed H1 selections and baseline certificates/statistics; obsolete row-control arrays are released after fixing similarities, and truth energy is computed blockwise. Completed recipient checkpoints are skipped on restart.
