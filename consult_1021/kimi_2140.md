## Decision: **A, reframed as an oracle-first, shrink-only test**

This is the only candidate that attacks a measured scoring defect with a small code change and can be evaluated without trusting the local overall. B requires a new response-transfer mechanism despite the measured cross-line limits; C is useful infrastructure work but produces no better artifact by itself. The native-layout result already establishes that buying fidelity/jaccard with a large reach loss is unattractive, so A must demonstrate that per-target budgets avoid that tradeoff—not merely produce another positive local overall.

## Protocol: 150-minute hard stop

### Frozen prediction base

Use the same H1 predictions, cells, targets, v9 confidence ordering, amplitude, processing, DE test, and official scorer for every causal arm. Only the per-target call count and resulting call mask may change. MSE/PDS must remain identical; any change is an implementation bug.

Before starting, re-score the frozen v5b/v9a-like artifacts and confirm the previously observed component signs. Treat this only as an environment sanity check; do not fit weights or consult local overall.

### Arms

| Arm | Call budget |
|---|---|
| **Fixed** | Current v9: 885 calls for every target |
| **Oracle-shrink** | \(b_t=\min(885,\max(1,n_{\mathrm{real},t}))\); H1 truth used only for this diagnostic |
| **Source-shrink** | \(b_t=\min(885,\max(32,\operatorname{round}(\hat n_t)))\), defined below |
| **Uniform-matched** | One uniform budget for all targets, with exactly the same total calls as Source-shrink |
| **Native** | Existing native layout, included only as the measured fidelity/reach reference |

For Source-shrink, \(\hat n_t\) is the median responder count across the target’s existing public-source DE rows, using the frozen DE rule. Exclude H1 same-line/same-experiment rows from this estimate, and never use H1 reference \(n_{\mathrm{real}}\) for calibration. Missing or unusable source evidence means **keep 885**, not zero. Do not test other floors, multipliers, or estimators.

Fixed, Oracle, Source, and Uniform must all use the identical nested v9 confidence order. Uniform-matched distinguishes genuine per-target count information from the mechanical effect of making fewer calls; it is a control, not another budget sweep.

### Pre-registered gates

**1. Oracle headroom gate—run within the first 20–30 minutes.**

Relative to Fixed on the 79 H1 targets, require:

- raw fidelity: **Δ ≥ +0.05**
- raw jaccard: **Δ ≥ +0.02**
- raw reach: **Δ ≥ −0.01**

These demand roughly half the native fidelity/jaccard benefit without native’s −0.0514 reach collapse. If Oracle fails, abandon A immediately; do not build a better count estimator.

**2. Source-shrink pass gate.**

Relative to Fixed, require all of:

- fidelity **Δ ≥ +0.03**
- jaccard **Δ ≥ +0.01**
- reach **Δ ≥ −0.005**
- higher fidelity-plus-jaccard gain than Uniform-matched, with no worse reach
- a target-level bootstrap over the 79 targets—not a cell-level bootstrap—whose 95% CI for the fidelity-plus-jaccard improvement excludes zero

Also fail automatically if targets with \(n_{\mathrm{real}}\ge885\) lose more than **0.01 reach**; that catches the heavy-tailed case where source screens underpredict large responses and quietly destroy useful calls.

If CD4 is genuinely cheap, run it once as confirmation: fidelity and jaccard must improve and reach loss must remain ≤0.01. A CD4 failure kills the result; it is not another tuning set.

**Abandon A** if any gate fails, if Uniform-matched explains the gain, or if success requires post-hoc H1 calibration. Local overall—positive or negative—plays no role in the decision.

## Biggest way this could fool us

The biggest risk is a **denominator-driven H1 mirage**: shrinking \(n_{\mathrm{pred}}\) mechanically improves fidelity, H1 can be easier than D/E/F, and the local overall can package that as a win even when the official reach tradeoff is unfavorable. The cross-line-only provenance rule, Uniform-matched control, hard reach/jaccard gates, and stratification by \(n_{\mathrm{real}}\) are the checks. If the effect needs H1’s own source rows or disappears against Uniform-matched, it is not evidence for D/E/F.

## Materiality

Plainly: **I do not expect any of these options to move the official score materially toward the leaders tonight.** A leaves MSE/PDS untouched, and shrink-only nested calls cannot increase reach; the realistic prize is a small fidelity/jaccard repair, not the optimistic +0.05 component-matching scenario.

If either gate fails, stop rather than pivoting to B or tuning A until H1 looks good. Use the remaining hours for a deterministic clean rebuild of the safety predictions and an automated audit of all 300×3 target-context outputs—400 cells each, correct target/context coverage, gene and cell ordering, and input/output hashes—plus preserve the oracle/source component table as a permanent negative result.
