VERDICT / Build **renderer-aware source weighting**, not another representation model. Hypothesis: equal donor pooling overweights unreliable or incompatible sources; learning a few nonnegative source weights can reduce rendered expression MSE. This is cheap, directly portable, and tests the dominant error rather than merely direction quality.

EXPERIMENT / Replace uniform donor pooling with normalized source weights, regularized toward uniform. Fit weights using training-only cross-source reconstruction **after the existing count renderer**. Baseline: identical eligible donors, uniform pooling, existing 0.3 residual blend. Keep renderer, layout, features, and residual predictor identical between arms. Use a small fixed regularization grid; no architecture search.

PROTOCOL / Run eight retained-family holdouts—not the rejected new cell-line benchmark. Exclude each held-out family and related dataset derivatives from donor banks, residual-model fitting, weight fitting, and tuning. Refit the residual predictor once per fold and share it between arms; do not reuse potentially contaminated checkpoints. Same-target donors from independent training families are explicitly allowed: this tests donor transfer, not unseen-target generalization. Tune weights through inner training-family holdouts. Query controls may define background; query perturbation outcomes may only score predictions. Primary metric: family-macro-averaged rendered expression MSE on a fixed gene/layout mask, with paired target-level errors. Cap execution at 48 CPU-hours.

KILL TEST / Require ≥3% relative MSE reduction, improvement in ≥6/8 families, and a paired hierarchical bootstrap 95% interval excluding zero. Otherwise reject source weighting as the next development priority. If retained data cannot reconstruct held-out expression and control backgrounds in the renderer’s units, **do not substitute direction correlation**: this experiment cannot establish the claimed MSE benefit.
