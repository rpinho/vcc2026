VERDICT: Test a **cell-context-conditioned signed-DE editor**, not another pooling or amplitude adjustment.
EXPERIMENT: Train one shared CPU CatBoost classifier to predict **up-DE / down-DE / non-DE** for each perturbation–gene pair. Use gene identity, recipient untreated gene/target expression, recipient baseline PCs, and donor-specific signed responses and DE calls.
PROTOCOL: Nested leave-one-family-out across all eight families. Build training examples by treating each training family as a pseudo-recipient; exclude both that recipient and the outer test family from its donor pool. Obtain labels using the official DE procedure. Start with depth 6, 300 trees, and ≤500k sampled training pairs per outer fold. Apply confident predictions (probability ≥0.8) to the incumbent: change sign for up/down, zero for non-DE; otherwise leave unchanged. Retain original absolute magnitudes for nonzero predictions. Score rendered cells with the official scorer.
KILL TEST: Kill unless macro official composite **and** direction_fidelity improve, composite improves in ≥6/8 families, and macro signature Jaccard does not decline. No MSE-based rescue.

This directly learns **which genes respond, and in which direction**, conditioned on recipient biology. Donor disagreement becomes an input rather than something averaged away. Preserving retained magnitudes isolates directional/support correction from the global shrinkage already disproven.

The important uncertainty is whether eight families contain transferable context–response relationships. Strict family holdouts test exactly that; random perturbation–gene splits would substantially overstate the evidence. This is a bounded CPU experiment, not a claim that baseline expression necessarily determines perturbation response.
